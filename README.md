Machine Learning project to predict employee attrition using Logistic Regression with L1 and L2 Regularization.
# Employee Attrition Prediction

## Project Overview
This project predicts whether an employee is likely to leave the company using supervised machine learning techniques.

## Objectives
- Build a baseline Logistic Regression model
- Improve performance using L1 (Lasso) Regularization
- Improve performance using L2 (Ridge) Regularization
- Compare all models and recommend the best one

## Dataset
The dataset contains 900 employee records with features such as:
- Age
- Salary
- Job Satisfaction
- Work-Life Balance
- Training Hours
- Bonus
- Experience
- Other employee-related attributes

**Target:**
- Leave Company (Yes/No)

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Evaluation Metrics
- Accuracy Score
